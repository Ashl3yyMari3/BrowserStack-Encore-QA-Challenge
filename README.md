# BrowserStack Encore QA Challenge - Tickets 1-9

## Ashley Cichy | QA Engineer & Computer Science Student

This repository documents my complete QA assessment of **Encore**, an Android event-ticket booking application tested during the BrowserStack Encore QA Challenge.

The challenge combined manual testing, exploratory testing, AI-assisted test design, mobile automation, cross-device validation, accessibility analysis, root-cause analysis, and release-readiness decision making.

Tickets **1-4 were required**, while Tickets **5-9 were optional advanced challenges**. I completed all nine tickets.

---

## Project Overview

The goal of the challenge was to evaluate the quality and release readiness of the Encore mobile application using BrowserStack's testing platform.

My work included:

- Reviewing and analyzing product requirements
- Designing and expanding test coverage
- Performing manual and exploratory testing
- Generating AI-assisted test cases
- Creating and executing mobile automation
- Testing across multiple Android devices and OS versions
- Investigating application and automation failures
- Performing root-cause analysis
- Conducting accessibility testing
- Validating seat inventory and booking behavior
- Evaluating payment-flow behavior
- Assigning defect severity
- Making release recommendations
- Documenting findings with screenshots, test sessions, reports, and supporting evidence
